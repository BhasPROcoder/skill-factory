# Print Production Handoffs (PRT)

Reconcile print production intent with quantity, proof, separation, boundary, personalization and assembly evidence without prescribing machinery operation.

Macro-area: Visual Arts, Photo & Video

Pick the skill whose triggers best match the request. If none match, use the closest description; if still none, answer without a skill.
