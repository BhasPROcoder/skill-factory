## Suggested consolidation

Do not copy these folders wholesale. The source has useful operational ideas but also personal business assumptions, changing product details, unsourced numerical claims, plugin-only wrappers, and duplicated context-management content. Prioritize distinct missing methods: inference cost accounting, adaptation diagnosis, LLM evaluation, persistent-memory maintenance, evidence-driven skill revision, context handoff, bounded orchestration, and local-inference envelope testing. Software continuation, requirements elicitation, implementation verification, and visual component construction need explicit task boundaries to avoid another family of overlapping umbrella skills.

No new skills were authored in this comparison. No current third-party claims were verified online; this report deliberately recommends removing or verifying them rather than treating the source as authoritative. The mappings are based on selected actual procedures and registry discovery, not a full semantic audit of every library file.
